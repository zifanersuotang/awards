# JSP-000672 / Erdős 815: statement review

[Original problem](https://www.erdosproblems.com/815).

The original universal eventual-cycle assertion quantifies over every k≥3, then a size threshold depending on k. DegreeThreeCritical encodes exactly 2n−2 edges and a degree-at-most-two vertex in every nonempty proper induced subgraph. The source constructs arbitrarily large examples excluding the non-induced cycle C23 and negates the original quantifier pattern. This is enough to disprove the universal assertion, but does not settle every odd cycle length or the still-open even-k variant. The retained source credits Narins, Pokrovskiy and Szabó for the disproof.
