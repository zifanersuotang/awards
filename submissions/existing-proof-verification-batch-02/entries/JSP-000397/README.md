# JSP-000397 / Erdős 491

For a real-valued arithmetic function additive on coprime arguments, uniformly bounded consecutive differences imply f(n)=c log(n)+O(1) as n tends to infinity. More quantitatively, a nonnegative bound M on the absolute consecutive differences gives a coefficient c with |f(n)-c log(n)| <= 2M for every positive integer n; complete additivity of the original function is not assumed and exact equality with c log(n) is not asserted.
