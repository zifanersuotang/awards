# JSP-000521 / Erdős 641

No function F of the number of cycles can ensure that every finite graph with chromatic number at least F(r) contains r pairwise edge-disjoint cycles on exactly the same nonempty vertex set. The failure already holds at r=2: for every chromatic threshold there is a finite graph with no nonempty 4-regular subgraph, whereas two such cycles would give one. No quantitative rate in terms of the exact number of vertices is claimed.
