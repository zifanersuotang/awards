# JSP-000547 / Erdős 673

For G(n), the sum of each positive divisor divided by its next larger divisor, every fixed real threshold is exceeded on a set of natural density one. The ordinary summatory function over 1<=n<=X is asymptotic to X log X with leading constant 1 along natural X, and the average (1/X) times the sum over 1<=n<=X tends to infinity.
