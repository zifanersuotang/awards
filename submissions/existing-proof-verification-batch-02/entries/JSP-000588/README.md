# JSP-000588 / Erdős 720

For two-color size Ramsey numbers defined by the least edge count of actual finite hosts, paths of n edges and cycles of n edges have eventual O(n) upper bounds. Therefore the proposed path/n divergence is false, and both path/n^2 and cycle/n^2 tend to 0. All sufficiently large n, including both cycle parities, are covered.
