# JSP-000393 / Erdős 485

For rational polynomials with exactly k nonzero coefficients, the attained minimum f(k) of the number of nonzero coefficients in their squares tends to infinity as k tends to infinity. The development also proves the explicit estimate terms(P) <= 1 + 32^(2^t), where t=terms(P^2) and terms(P)>=2; it does not claim the later logarithmic lower bound, arbitrary powers, or a theorem over all coefficient fields.
